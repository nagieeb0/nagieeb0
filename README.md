### ✍️ Arabic, rendered correctly

Draw `"الفاتورة رقم 1042"` with a plain PDF writer and you get disconnected letters and `2401`. These fix that, in pure Elixir:

| | |
|---|---|
| [**qalam**](https://github.com/nagieeb0/qalam) · قلم | Text layout for PDF generators — bidi run splitting, shaping, measuring, wrapping. |
| [**bidi**](https://github.com/nagieeb0/bidi) | The Unicode Bidirectional Algorithm (UAX #9). |
| [**sfnt**](https://github.com/nagieeb0/sfnt) | Font subsetting — strips an OpenType/TrueType face down to the glyphs you used. |
| [**kashida-mono**](https://github.com/nagieeb0/kashida-mono) | Turns a proportional Arabic font into a monospace one that actually works in a terminal. |
